# Work items

Open items, one per file in this folder. Work is organised in work items,
one conversation each: an item says what it's for, what it waits on, what
was found along the way and when it's done, so the next conversation starts
from the file, not the chat. This one is a made-up example of the pattern;
[Work items](../README.md#work-items) in the README says what palace does
with them.
