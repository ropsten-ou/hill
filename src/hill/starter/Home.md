# Home

A few notes to try palace on. They're yours: change them, add to them,
or delete the lot once you've seen how it goes.

- [The garden](garden/README.md) is a made-up project, with a README and
  one work item, [the raised beds](garden/work/001-raised-beds-sample.md).
- [[Keys]] lists the keys to start with.

The list on the left shows every note in this folder, and its folders
first. Select a note and the preview shows it, with what it links to
and what links to it. Press `m` for the links map, which starts here,
at the home note: palace takes the note called Home, Index or Start
here, else the one with the most links.
