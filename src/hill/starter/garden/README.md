# The garden

Vegetables at the back of the house: four raised beds along the south
fence, a compost bin, and a water butt off the shed's gutter.

This is a made-up project, to show what a project looks like in palace:
a folder with a README, and its work in [work items](work/README.md),
one Markdown file each.

## Beds

| Bed | This year | Next year |
|---|---|---|
| 1 | potatoes | beans and peas |
| 2 | beans and peas | cabbages |
| 3 | cabbages | roots |
| 4 | roots | potatoes |
